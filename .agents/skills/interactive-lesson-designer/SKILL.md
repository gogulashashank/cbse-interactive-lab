# Interactive Lesson Designer

Use this skill when designing, structuring, or reviewing educational content and lesson flows for the CBSE Interactive Lab.

## Core Requirements

1. **Pedagogical Flow**:
   - Structure every lesson strictly around the five-stage inquiry sequence: **predict → investigate → explain → apply → review**.
   - Ensure learners commit to an initial prediction before manipulating simulation parameters in the investigate phase.

2. **Learning Objectives & Misconceptions**:
   - Clearly define the primary learning objective(s) at the start of the lesson design.
   - Explicitly identify and address likely student misconceptions (e.g., confusing reduced force with reduced mechanical work on an inclined plane).

3. **Language & Tone**:
   - Use clear, encouraging, age-appropriate language suitable for Indian CBSE students in Classes 9–12.
   - Define technical terms clearly in context before relying on symbolic notation.

4. **Curriculum Alignment & Integrity**:
   - **Never invent official curriculum references**, chapter numbers, or NCERT section codes.
   - Explicitly mark all CBSE alignment metadata as **unverified** until directly source-checked against official NCERT/CBSE syllabus documents.
   - Require formal **educator review** before any lesson content is labelled as approved or classroom-ready.
